## Redesign direction, not an approved training specification

Use the diagnostic to distinguish orientation sensitivity from omitted role
selection, without forcing a unique failure cause. Do not simply extend the
old deterministic random-label fit or train an orientation ensemble.

The eventual normalized member-state distribution must support alternative
MW/M31 assignments and a shared/subcell M33, while conserving SAME-field mass
and moments. Native random choices can be samples for a conditional
distribution; they are not intrinsically invalid data. The mismatch is treating
one such sample as uniquely recoverable, and scoring a single deterministic
allocation against it as though it were the uniquely true LG identification.

Actual position/sky direction/distance/velocity observations should select
among hypotheses with observational and stellar-to-COM uncertainties, not by
introducing hidden true IDs or catalogue centers as inference inputs. Existing
`cf4_lg_observation_contract.py` supplies only the observation interface for
an already specified state, NOT a new-field candidate finder. A future
observation-conditioned proposal q(S|F,d) cannot itself be multiplied as an
independent likelihood: require a defined joint target and correct proposal
weighting to use d once. Missing q_F/selection/velocity/member calibration
remain open. Freeze the concrete next learning budget/model only after this
result; Fable plan audit and user approval before that next training bundle.
